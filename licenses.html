Browser conversion libraries

Fileflow loads some conversion libraries from public CDNs when a corresponding tool is used. Their licenses and versions are controlled by their respective projects and distributions.

  • Mammoth.js — DOCX text and HTML extraction.
  • PDF.js — PDF text extraction.
  • SheetJS Community Edition — spreadsheet parsing and export.
  • jsPDF — PDF creation.
  • docx — DOCX creation.
  • lamejs — MP3 encoding.
  • @ffmpeg/types — TypeScript declarations (MIT).

Version numbers and license terms can change when dependencies are updated. The source package manifests and upstream license files are authoritative for each distributed version.
