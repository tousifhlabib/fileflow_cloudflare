THE QUICK GUIDE

Know what a document conversion preserves.

PDF

Extract readable text

PDF to text or DOCX uses text extraction. Scanned pages are not OCR-processed.

DOCX

Focus on document text

DOCX conversions may not preserve page layout, styles, images, or other formatting.

XLSX

First worksheet only

Spreadsheet conversions use the first sheet; styling, formulas, and workbook features may change.

Supported conversions include PDF, DOCX, XLSX, XLS, CSV, and TXT pairs shown in the selector. Libraries load on demand from CDNs, so an internet connection is needed. There is no specific app-enforced document size limit; browser memory and file complexity can constrain processing.
